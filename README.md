# Wedding Atlas website

The live site for [weddingatlas.net](https://weddingatlas.net).

- `index.html` — the whole site (one page)
- `images/` — venue photos and sample shortlist pages
- `CNAME` — tells GitHub Pages which domain the site lives on

To change anything, ask Claude: it updates the files here and GitHub Pages republishes the site automatically within a minute or two.
